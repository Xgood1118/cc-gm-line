# 线段绘制

纯 Python 标准库实现的线段绘制器：任意斜率连通、端点对调对称、1..9 像素
线宽、圆形端帽、基于覆盖率的抗锯齿，自带无第三方依赖的 PNG 编码。

## 实现要点

### 几何模型：胶囊体 + 圆形端帽（round cap）

一条宽度 `width` 的线段被建模为**胶囊体**——到中心线的距离不超过
`r = width / 2` 的所有点，两端由半圆收口，即 **round cap（圆形端帽）**，
不是硬直切口（butt cap）。

中心线沿轴向两端各延长 `r`，再扣上半径 `r` 的半圆帽，因此笔画在端点之外
共伸出一个线宽 `width`，轴对齐笔画能把两个端点像素完整涂满（不会因圆帽
削角而发灰）。像素 `(x, y)` 的中心位于整数坐标 `(x, y)`，像素方块为
`[x-0.5, x+0.5) × [y-0.5, y+0.5)`。

折线（`draw_polyline`）逐段绘制，相邻段的圆帽在公共顶点处重叠，
连接处不会断裂。

### 抗锯齿：4×4 网格超采样

每个像素取 4×4 = 16 个均匀采样点，**覆盖率 = 落在胶囊体内的采样点数 / 16**，
共 17 级灰度。最终颜色按覆盖率与画布已有颜色做 source-over 混合，因此边缘
像素的灰度严格等于其覆盖率，同色线段重叠也不会产生接缝。轴对齐线的中心线
像素覆盖率为 100%，保持锐利不发虚。

### 连通与对称

- 宽度 ≥ 1 时，线段穿过的每个像素至少有一个采样点命中，任意斜率
  （水平、垂直、45°、接近竖直）都连成一条 4-连通的线，无断点、无重复落点。
- 胶囊体几何关于两个端点完全对称，距离计算与绘制方向无关，起点终点对调后
  逐像素的落点集合与灰度完全一致（测试用像素集合比较，不比较绘制顺序）。

## 运行

```
python -m line.cli data/segments.txt --size 320,240 --out lines.png
python -m pytest tests -q
```

`segments.txt` 六条线：缓斜率、陡斜率、水平、垂直、对角，宽度从 1 到 9。

## API

- `Image(width, height, background)`：内存 RGB 画布，`set/at` 读写像素。
- `draw_line(img, x0, y0, x1, y1, color)`：1 像素宽抗锯齿线。
- `draw_thick_line(img, x0, y0, x1, y1, color, width)`：圆帽抗锯齿粗线，
  `width` 取 1..9（任意正数均可）。
- `draw_polyline(img, points, color, width=1, closed=False)`：折线，
  `closed=True` 时首尾闭合。
- `save_png(img, path)`：手写 zlib + struct 的 PNG（8-bit RGB）编码。
- `load_segments(path)`：解析 `seg` 格式的线段描述文件。
